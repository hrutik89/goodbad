01 — COMPARISON

HTML and HTML5: key differences

FeatureEarlier HTML (e.g., HTML 4.01)HTML5
DoctypeLong declaration, such as HTML 4.01 Transitional<!DOCTYPE html> — simple and short
Semantic structureOften relied on generic div elementsProvides header, nav, main, section, article, and footer
Audio and videoOften required third-party pluginsNative audio and video elements
GraphicsUsually depended on images or pluginsSupports canvas and SVG integration
FormsFewer built-in input typesInput types such as email, date, number and built-in validation
Storage and APIsLimited standard browser featuresIntroduced/standardized web platform capabilities such as Web Storage and geolocation support through APIs
Accessibility and meaningMeaning depended more on markup conventionsSemantic elements help browsers, assistive technology, and developers understand page regions

Note: HTML5 is the commonly used name for the major HTML revision that introduced many of these features. HTML is now maintained as a living standard, so modern HTML continues to evolve.

02 — GOOD HTML

Use semantic tags and a clear structure

Semantic elements describe the purpose of content. A logical heading order and meaningful labels make pages easier to maintain and navigate.

✓

Good HTML

Meaningful and well organized

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport"
        content="width=device-width,
        initial-scale=1.0">
  <title>Student Blog</title>
</head>
<body>
  <header>
    <h1>Student Blog</h1>
  </header>
  <nav aria-label="Main navigation">
    <a href="#article">Article</a>
  </nav>
  <main>
    <article id="article">
      <h2>Learning HTML5</h2>
      <p>Semantic HTML adds meaning.</p>
    </article>
  </main>
  <footer>© 2026 Student Blog</footer>
</body>
</html>
  • Uses semantic page landmarks
  • Includes language and viewport metadata
  • Uses a logical heading hierarchy
  • Uses a descriptive page title
!

Bad HTML

Unclear and poorly structured

<html>
<head><title>Page</title></head>
<body>
  <div>
    <font size="7">Student Blog</font>
  </div>
  <div>
    <a href="#">Click here</a>
  </div>
  <div>
    <h4>Learning HTML5</h4>
    <div>Semantic HTML adds meaning.
    <div>More text
  </div>
</body>
</html>
  • Generic divs do not explain content roles
  • Deprecated presentational font element
  • Missing language and viewport metadata
  • Heading levels and nesting are inconsistent

Important: Browsers may still render poorly written HTML. “Bad HTML” here means less semantic, less accessible, harder-to-maintain markup—not necessarily that every line is invalid.

04 — CONCLUSION

Write HTML for people and browsers.

HTML5 introduced semantic elements and useful native browser features. Good HTML combines meaningful tags, valid nesting, accessible labels, and responsive metadata. CSS controls presentation; HTML describes the content and its structure.
